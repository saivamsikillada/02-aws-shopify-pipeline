# Amazon S3 Setup

## Objective

Amazon S3 is used as the storage layer for the Shopify Data Engineering Pipeline. It stores raw, processed, and Gold layer data.

## Bucket Name

shopify-data-pipeline-ashwini

## Folder Structure

```text
shopify-data-pipeline-ashwini/
│
├── raw/
│   ├── mysql/
│   ├── pos/
│   ├── salesforce/
│   ├── saphana/
│   └── teradata/
│
├── processed/
│   ├── customers/
│   ├── inventory/
│   ├── orders/
│   ├── payments/
│   └── products/
│
├── gold/
│   ├── dim_customer/
│   ├── dim_product/
│   ├── fact_orders/
│   ├── fact_payments/
│   └── inventory_summary/
│
├── scripts/
└── logs/
```

## Purpose of Each Folder

### raw/
Stores the original source data received from different source systems.

### processed/
Stores cleaned and transformed datasets generated by AWS Glue ETL jobs.

### gold/
Stores business-ready datasets for analytics and reporting.

### scripts/
Stores AWS Glue ETL scripts.

### logs/
Stores ETL execution logs.
